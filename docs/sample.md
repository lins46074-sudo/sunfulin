# 星辰笔记 App 产品说明（示例文档）

> 这是一份示例文档，用来验证 RAG 流程是否跑通。
> 你可以随时删掉它，换成自己的 .txt / .md 文档，然后重跑 `uv run python ingest.py`。

## 一、产品简介

星辰笔记是一款面向个人的本地优先笔记应用，2024 年 3 月上线首个版本，
当前最新版本为 2.4.0，于 2025 年 1 月发布。

## 二、价格方案

- 免费版：单设备，最多 200 条笔记，不含云同步。
- 专业版：每月 18 元，或每年 168 元。设备数不限，云同步提供 10GB 存储空间。
- 团队版：每人每月 35 元，起订 5 人，含协作编辑与权限管理。

使用教育邮箱认证后，可享受专业版 5 折优惠。

## 三、核心功能

1. 全文检索：支持中文分词，检索响应时间小于 200 毫秒。
2. 双向链接：输入 `[[` 即可关联另一篇笔记。
3. 版本历史：专业版保留最近 90 天的历史版本。
4. 导出格式：支持 Markdown、PDF、Word 三种格式。

## 四、常见问题

**问：免费版的笔记数量超了怎么办？**
答：超出后无法新建笔记，但已有笔记仍可正常查看和编辑。升级专业版即可解除限制。

**问：云同步冲突怎么处理？**
答：同一篇笔记在两台设备上同时修改时，系统会保留两个版本，并在笔记顶部提示手动合并。

**问：支持哪些平台？**
答：Windows、macOS、iOS、Android 四个平台，Linux 版本计划在 2026 年推出。
